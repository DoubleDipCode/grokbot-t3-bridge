# Brief footer

Append this to every brief a bot sends to T3. Replace `<bot-name>` with the bot's name as used in `set-webhook.sh` (lowercase letters, digits, `-`, `_`).

---

**Callback setup (do this first, before anything else):**

```bash
marker=.atoll; [ -d .atoll ] && marker=.atoll/marker.json
printf '{"agent":"<bot-name>"}\n' > "$marker"
printf '%s\n' "$marker" .atoll-status >> "$(git rev-parse --git-common-dir)/info/exclude"
```

Run these at the root of this worktree. If you know the issue this work belongs to, add it to the marker: `{"agent":"<bot-name>","issue":"AP-123"}`. The second line keeps the marker and status files out of git. Never commit them.

**Before you end every turn,** overwrite `.atoll-status` at the worktree root. The first line is exactly one of `done`, `needs_input` or `failed`. After that, add a short note:

- `done`: the work is finished, the review step has run, and the PR is open. Include the PR URL.
- `needs_input`: you need a decision. Write the question and the options.
- `failed`: you are stuck. Write what you tried and what blocked you.

Example:

```bash
printf 'needs_input\nShould the export include archived rows? Options: (a) yes, (b) no, (c) behind a flag.\n' > .atoll-status
```

**If you need a decision, write `needs_input` and end your turn.** Do not wait inside the thread for an answer. The answer will come as a new message in this thread.

**Never remove this worktree yourself,** not even at the end. Do not run `git worktree remove` on it or delete its folder. Cleanup happens after your final turn.

**Write files with your file tools, not with shell heredocs.** Create and edit files with the Write/Edit tools. If you need a script, save it to a file and run the file. Avoid `cat > file <<'EOF'` and `python3 - <<'EOF'` with long bodies: Claude Code's Bash check reads the whole command, and when the body merely mentions `rm` it stops on a "Dangerous rm operation not ruled out" approval prompt that nobody is there to answer. Keep shell commands short. This is about not triggering the prompt; never try to get around or switch off a permission check.

**Stay on this task in this worktree.** If you are asked to start an unrelated task, say so and end the turn with `needs_input`. It needs a new thread.


The sweep can send `stalled <minutes>m <original status>` after 45 minutes
without a status change or successful ping (`GROKBOT_STALL_MINUTES` overrides
the threshold). It excludes `done`, uses the separate two-hour reminder for
`waiting`, and skips worktrees with a running harness. It attempts one stall
ping per status revision. Read the thread before taking action. Agents must
write their normal status; `stalled` is generated by the sweep.
